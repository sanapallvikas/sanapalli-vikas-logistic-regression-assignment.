Logistic Regression Assignment

Overview

This project demonstrates Logistic Regression using Python and a Jupyter Notebook.

Files

* Logistic Regression.ipynb — Notebook containing the analysis and model implementation.
* Logistic Regression.csv — Dataset used for the assignment.

Technologies Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Scikit-learn

Objective

To explore Logistic Regression and understand how it can be used for classification tasks.

How to Run

1. Download or clone this repository.
2. Install the required Python libraries.
3. Open the notebook in Jupyter Notebook.
4. Run the cells in order.
